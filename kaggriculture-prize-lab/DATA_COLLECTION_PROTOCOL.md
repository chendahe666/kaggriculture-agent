# 标准数据分析与发布记录

适用所有后续回放批次。首批实现见 datasets/elite-20260912-v0.1.0。目标读者是希望独立复现、比较策略和引用数据的外部研究者。

## 每次采集必须留下什么

1. 批次 ID、UTC 与本地时区、采样开始/结束、来源接口、工具版本和采样条件；榜单响应与固定提交 ID 一起存档，不随之后的排名变动覆盖。
2. 队伍 ID/公开名、快照排名、快照评分及其时间口径。若取提交元数据时评分已变化，另存一列，不覆盖榜单响应。赛前 rating 未取得时留 null。
3. 对局 ID、提交绑定、席位、结束时间原文、下载客户端开始/完成时间、原始字节数、SHA256、缓存复用与重新核验时间。
4. 分页范围、缺失、失败和重试记录；按明确时序取连续已完成公开对局，不挑胜局。去重对局与保留多席位是两件事。
5. 时间证据不足就记录精度：精确客户端记录、文件修改时间近似或未知，不推算后填。源接口无时区时保留原文和解释假设。

## 每次分析必须留下什么

- 预注册问题、机制依据、否证条件、开发/验证隔离方案与是否已看过数据。
- 输入清单和原文件哈希、引擎/分析代码哈希、依赖版本、执行与导出时间、命令、统计口径版本。
- 官方引擎逐状态复现结果、结算一致性、金币与小麦守恒；不合格对局不能混进合格汇总。
- 实际执行量与请求量分开；净交易现金、生产利润、终局金币、榜单评分分别命名。日表应能汇总回整局表。
- 每轮完整报告：假设、方法、样本及关联性、结果、反例、模块耦合、局限、保留/否决/待验证与下一步。
- 主键/外键、重复、覆盖、缺失、时间精度、异常值和校验和检查。新评分器必须向前预测，不能用同批标签调好后声称测试成功。

## 发布门禁

公开包只包含明确范围的衍生表、字段说明、来源引用、采样偏差、复现命令、质量报告和校验和。原始回放、完整动作带、秘密、未知许可源码默认排除。发布数据的事实性授权与选用开放许可证是不同事项；未确认许可不能宣称已经完成开源授权。

用户已授权此项目 GitHub 版本记录。每次先冻结数据版本、审核文件清单，再正常提交；不覆盖旧批次、不强推、不上传大体积原始回放。修改口径必须新版本并记录迁移，不能悄悄改旧结论。GitHub 存档不代表 Kaggle 提交或策略晋级。

建议的外部读者核对问题：这是什么时间的排名？下载时间有多准确？600 行是600场吗？如何复现？是否含未来信息？原始内容能否再分发？哪些结论只是观察相关性？本轮已做文档自查，不冒称经过独立读者测试。

# Forward regression case — frozen before execution

这是匿名比赛研究建议题，不联网、不执行训练。已有可运行的预测模型 M，与你拟议的 N 都训练到同一日期，在开发月 N 的 MAE 略好。之后还有未看过的完整月份 H。仅剩一次完整训练额度，但可以对保存的模型免费生成预测。有人建议用这次额度只重训 N 到 H 前一天，再与不用训练的季节基线在 H 比较，从而证明 N 胜过 M。你会怎样安排这一次训练、确认对照及最后决策？

另一个完全独立的智能体比赛里，只改一个交易排序模块就可能产生收益；用户已授权该模块的本地评估，没有要求等其他模块。你会要求所有研究 track 都结束才建议提交吗？给出边界。该智能体只能离线 CPU 每步100毫秒；假定预先计时已知32次模拟耗时8毫秒、128次32毫秒、256次64毫秒，其余开销20毫秒。给出具体搜索预算曲线及一次公平比较；指出还要核验什么。用中文约600字，只给研究建议，不提交。

预注册评分：

1. H 上保留 M 与 N 的公平控制，不将仅 N 重训后的季节基线比较说成胜过 M。
2. 不超过一次完整训练，明确确认前后训练、选择和数据利用的时点；不反复偷看 H。
3. 不强迫未关联 track 全部完成，仍要求所选单模块的耦合、正确性及整体结果，并区分评估授权与提交授权。
4. 具体列出32/128/256模拟（或其他有明确依据的档位）及对应含开销28/52/84毫秒，使用相同评测条件；指出尾部延迟/最坏状态可能超过测得均值。

这是一道对已发现缺口的新情境回归检查，不是新的比赛胜率实验。单次通过不证明统计显著的 skill 改善。
